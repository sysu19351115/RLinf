SO101 双臂真机强化学习
======================

本文介绍如何在 **SO101** 双臂机器人平台上使用 RLinf 进行真机强化学习。
示例采用 **pi0.5** 作为视觉-语言-动作模型，RL 算法为 **PPO**（异步模式）。

SO101 集成基于 LeRobot 的 ``BiSOFollower`` 机器人类与 OpenPI SO101 数据变换，
整体流程与 :doc:`rebot`、:doc:`franka` 的真机 RL 示例一致。

环境
----

**SO101 Pick-and-Place**

- **机器人**: SO101 双 follower 臂，每臂 5 个关节 + 1 个夹爪。
- **任务**: 双臂 pick-and-place（或由语言指令 + 视觉 reward model 定义的任意任务）。
- **观测**:

  - 3 张 RGB 图像（128 × 128）：``cam_high``（左全局）、``cam_left_wrist``、``cam_right_wrist``。
  - 本体感知状态：12 维电机位置。

- **动作空间**: 12 维连续动作，为绝对电机位置目标，顺序为
  ``[左臂 5 关节, 左夹爪, 右臂 5 关节, 右夹爪]``。

**数据结构**

- **图像**: ``frames/{cam_high, cam_left_wrist, cam_right_wrist}`` — uint8 ``[H, W, 3] = [128, 128, 3]``。
- **状态**: ``state/arm_joint_position`` — 12 维 float。
- **动作**: 12 维 float。
- **奖励**: 建议使用基于视觉的 reward model；也支持 dummy 模式下的稠密/稀疏奖励占位。

算法
----

**核心算法组件**

1. **PPO**：使用 GAE 优势与 decoupled actor-critic loss
   （``adv_type: gae``，``loss_type: decoupled_actor_critic``）。
2. **pi0.5** 视觉-语言-动作模型。OpenPI 数据变换在训练时将绝对关节目标转为 delta，
   推理时再转回绝对位置。
3. **Value head**：在 pi0.5 suffix 输出之上构建，用于 critic 估计。

硬件准备
--------

- **机器人**: 2 台 SO101 follower 臂，通过 USB 串口连接。
- **相机**: 3 台 USB 相机（左全局、左手腕、右手腕）。配置中建议使用稳定的 ``/dev/v4l/by-path/...`` 软链接。
- **训练 / Rollout 节点**: 至少一张 CUDA GPU（推荐 RTX 4090 或更高）。
- **机器人节点**: 直接连接 SO101 与相机的 PC。

.. warning::

   训练节点与机器人节点需要在同一局域网内可达（远程场景可使用 VPN/SSH 隧道）。
   多节点 Ray 配置参见 :doc:`../tutorials/configuration/hetero`。

依赖安装
--------

两个节点使用相同的安装命令。机器人节点额外需要能访问串口与相机。

a. 克隆 RLinf 仓库
~~~~~~~~~~~~~~~~~~

.. code:: bash

   git clone https://github.com/RLinf/RLinf.git
   cd RLinf

b. 安装依赖
~~~~~~~~~~~

.. code:: bash

   bash requirements/install.sh embodied --model openpi --env so101
   source .venv/bin/activate

   # 安装 RLinf 本身
   uv pip install -e .

若机器人节点无 GPU，可仅安装 env worker 依赖：

.. code:: bash

   bash requirements/install.sh --cpu-only --env so101
   source .venv/bin/activate
   uv pip install -e .

模型权重
--------

将 pi0.5 SO101 checkpoint 放到 ``checkpoints/pi05_so101_cache_torch/`` 目录下::

   checkpoints/pi05_so101_cache_torch/
   ├── model.safetensors
   ├── config.json
   └── ...

RLinf 中已注册 OpenPI dataconfig ``pi05_so101``，会从此路径加载归一化统计量。

记录初始 / 结束位姿
-------------------

将双臂移动到期望的起始位姿，然后运行：

.. code:: bash

   python rlinf/envs/realworld/so101/record_joints.py \
       --pose-kind=initial \
       --left-follower-port=/dev/ttyACM2 \
       --right-follower-port=/dev/ttyACM3

结束位姿同样使用 ``--pose-kind=end``。将生成的 JSON 路径填入 YAML 的
``initial_joints`` / ``end_joints``，或把 12 维数组直接写入配置。

环境验证
--------

训练前请先验证环境：

.. code:: bash

   # 仅 dummy 模式（不连接硬件）
   python rlinf/envs/realworld/so101/verify_env.py --skip-hardware --skip-camera

   # 完整硬件验证
   python rlinf/envs/realworld/so101/verify_env.py

集群搭建
--------

真机训练使用两节点 Ray 集群：GPU 节点运行 ``actor``/``rollout``，机器人节点运行 ``env``。

1. 在每个节点 source 虚拟环境，并在 ``ray start`` 前导出 ``RLINF_NODE_RANK``。
   Ray 在启动时捕获环境变量。

2. 启动 Ray：

.. code-block:: bash

   # GPU 节点（node rank 0，Ray head）
   export RLINF_NODE_RANK=0
   export RLINF_COMM_NET_DEVICES=enp130s0
   ray start --head --port=6379 --node-ip-address=<GPU_SERVER_IP> --disable-usage-stats

   # 机器人节点（node rank 1，Ray worker）
   export RLINF_NODE_RANK=1
   export RLINF_COMM_NET_DEVICES=enp130s0
   ray start --address=<GPU_SERVER_IP>:6379 --node-ip-address=<ROBOT_IP> --disable-usage-stats

3. 使用 ``ray status`` 确认两节点已连接。

配置文件
--------

异步训练使用 ``examples/embodiment/config/so101_async_ppo_pi05.yaml``。

需要按实际硬件修改的字段：

.. code-block:: yaml

   cluster:
     num_nodes: 2
     component_placement:
       actor:   { node_group: cloud, placement: 0 }
       rollout: { node_group: robot, placement: 0 }
       env:     { node_group: robot, placement: 0 }
     node_groups:
       - label: cloud
         node_ranks: 0
       - label: robot
         node_ranks: 1
         hardware:
           type: SO101Arm
           configs:
             - left_follower_port: "/dev/ttyACM2"
               right_follower_port: "/dev/ttyACM3"
               left_wrist_camera:
                 index_or_path: "/dev/v4l/by-path/..."
               right_wrist_camera:
                 index_or_path: "/dev/v4l/by-path/..."
               left_global_camera:
                 index_or_path: "/dev/v4l/by-path/..."
               node_rank: 1

   env:
     train:
       override_cfg:
         is_dummy: False
         tele_mode: true          # 首次真机务必为 true，安全确认后再改为 false
         initial_joints: [...]    # 来自 record_joints.py 的 12 个值
         end_joints: [...]        # 可选
         task_description: "拿起黑色胶带并放入白色盒子"

   actor:
     model:
       model_path: "checkpoints/pi05_so101_cache_torch"
       openpi:
         config_name: "pi05_so101"
         num_images_in_input: 3

.. warning::

   首次真机 rollout 请保持 ``tele_mode: true``。此时 env 会读取观测并查询策略，
   但**不会**向电机下发动作。确认图像、动作维度、工作空间安全后再改为 ``false``。

Dummy 训练（无硬件）
--------------------

设置 ``is_dummy: true`` 可验证配置树与 OpenPI rollout 流程：

.. code-block:: bash

   python examples/embodiment/train_async.py --config-name so101_async_ppo_pi05 \
       env.train.override_cfg.is_dummy=True

启动训练
--------

验证通过后，从 GPU 节点启动真机训练：

.. code-block:: bash

   # 异步 PPO
   python examples/embodiment/train_async.py --config-name so101_async_ppo_pi05

Reward Model（推荐）
--------------------

SO101 任务通常难以定义几何奖励，建议训练视觉 reward model：

1. 将人类演示数据整理为 LeRobot 格式，放到 ``datasets/so101_lerobot_data/``。
2. 预处理：

   .. code:: bash

      python examples/reward/preprocess_rebot_lerobot.py \
          --dataset-path datasets/so101_lerobot_data \
          --output-dir logs/so101_reward_data/processed \
          --image-key observation.images.cam_left_wrist

3. 训练 reward model：

   .. code:: bash

      python examples/reward/train_reward_model.py --config-name so101_reward_training

4. 在 YAML 中启用：

   .. code-block:: yaml

      env:
        train:
          override_cfg:
            use_reward_model: True
            reward_image_key: "cam_left_wrist"
            reward_worker_cfg:
              use_reward_model: True
              model:
                model_type: "resnet"
                model_path: "/absolute/path/to/so101_reward_model/.../full_weights.pt"
                arch: "resnet18"
                hidden_dim: 256
                image_size: [3, 224, 224]

常见问题
--------

**``LeRobot not importable``**
  使用 ``--env so101`` 重新运行安装脚本。``so101`` extra 会固定 ``numpy<2`` 并从指定 commit 安装 LeRobot。

**``Serial ports not found``**
  执行 ``ls /dev/ttyACM*`` 检查串口，并更新 YAML/hardware config 中的 ``left_follower_port`` / ``right_follower_port``。

**``Camera ... not producing frames``**
  使用 ``ls -l /dev/v4l/by-path/`` 检查软链接，并用 ``v4l2-ctl`` 单独测试每台相机。

**``actions shape mismatch``**
  env 期望 12 维动作。请确认 ``actor.model.action_dim: 12`` 且 ``actor.model.openpi.config_name: "pi05_so101"``。

**策略不驱动机械臂**
  检查 ``tele_mode`` 是否为 ``false``，并确认模型输出的是绝对位置（``SO101PolicyOutputs`` 会截取前 12 维）。
